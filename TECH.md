# Technical Notes

This project has **zero dependencies**.

- No npm packages
- No Python libraries
- No build step
- No bundler (Webpack, Vite, etc.)

It is a single self-contained `index.html` file using:
- Vanilla HTML5
- Vanilla CSS3
- Vanilla JavaScript (ES6+)
- Browser LocalStorage API

To "install": open `index.html` in a browser.
