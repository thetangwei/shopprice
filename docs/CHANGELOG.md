## [1.0.0] — 2026-03-26

### Added
- Split-screen POS layout (products left, cart right)
- Cash & Card payment with automatic change calculator
- Credit sales ("pe caiet") with customer name
- Undo last sale — cash, card and debt payments
- Full product CRUD with editable code and initial quantity
- Sortable stock table (click any column header)
- Low stock warning under 10 units
- CSV bulk import with auto Total Cost calculation
- CSV export for stock and all report tabs
- Statistics dashboard: sales, profit, investment, potential revenue
- Separate Cash / Card income totals
- Sales history with payment type column
- Daily revenue breakdown per day (cash / card / credit)
- Top products by profit and by quantity sold
- Customer debt tracking with partial/full payments
- Debt summary row (total / paid / remaining)
- Undo debt payment — restores to active debts
- Auto dark/light mode via OS preference
- 100% offline, zero dependencies, single HTML file
